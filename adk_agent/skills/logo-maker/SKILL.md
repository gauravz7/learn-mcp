# Logo Maker

## Workflow
1. In one line, capture the brand name and its vibe.
2. Write **one** prompt for a **minimalist, iconic, flat-vector** mark: centered, generous
   negative space, plain background, no text unless explicitly requested.
3. Call the **`generate_image`** tool with `aspect_ratio="1:1"`.
4. Report the `resource_uri` and describe the concept in one sentence.

## Rules
- Simple, memorable, scalable — avoid photorealism, gradients, and clutter.
