# Social Post

## Workflow
1. In one line, name the platform and the message.
2. Write **one** vivid image-prompt paragraph (concrete subject, style, lighting, mood, palette).
3. Call the **`generate_image`** tool with `aspect_ratio="1:1"`.
4. Report the returned `resource_uri`, then offer **3 caption options** (each under 200 chars,
   2–3 relevant hashtags).

## Rules
- Square only (1:1).
- Keep the image prompt to a single paragraph.
