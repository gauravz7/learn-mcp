# Image-prompt recipe (L3 resource, loaded only when needed)

A strong image prompt names, in one flowing paragraph:

1. **Subject** — who/what, and what they're doing
2. **Setting** — where
3. **Style** — e.g. flat vector, oil painting, cinematic 3D render, risograph
4. **Lighting** — e.g. golden hour, neon rim light, soft studio
5. **Mood** — e.g. hopeful, ominous, playful
6. **Composition** — e.g. centered hero, rule-of-thirds, low angle, negative space at top for a headline
7. **Color palette** — 2–3 anchor colors

Template:
> "<subject> <doing what>, <setting>, <style>, <lighting>, <mood>, <composition>, <palette>."

Poster tip: leave **negative space at the top** so a headline can overlay cleanly.
